GITHUB SECRETS YANG DIPERLUKAN

Lokasi:
Repository > Settings > Secrets and variables > Actions

Tambah dua Repository secrets:

NAME
CLOUDFLARE_API_TOKEN

VALUE
Token Cloudflare yang mempunyai:
Account > Cloudflare Pages > Edit

NAME
CLOUDFLARE_ACCOUNT_ID

VALUE
Account ID Cloudflare yang memiliki project:
englishkidshub

Jangan masukkan token atau Account ID ke dalam index.html.
Jangan commit nilai secret ke repository.
